# Maintain generated artifacts

On creation or refresh, update the matching guide instead of adding another version. Inspect generated artifacts in the affected scope and their incoming links, queries and code references. Distinguish **current**, **stale—needs refresh**, **superseded**, and **completed/expired**. Age alone does not establish obsolescence; a newer scoped dataset cannot replace full-account, other-account or roster coverage. Seasonal availability remains unverified until its relevant dates are verified.

Archive truly superseded generated output and completed/expired guides retained only as history under `_System/Archive/`, with source date, reason and replacement link (or an explicit no-replacement note). Remove them from active home/dashboard recommendations while preserving history links and updating references to moved files. Keep still-useful guides current or visibly stale.

Preserve canonical records, checked actions, user notes, sole-source evidence and current rendering assets. Never delete by age or filesystem glob. Within authorized cleanup, delete only individually verified, unreferenced duplicate or regenerable agent artifacts; verify regeneration inputs exist. Record retained/updated/archived/deleted counts and unresolved cases in the existing account setup/refresh summary, not a new maintenance-log file per run.
