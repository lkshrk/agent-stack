# Existing providers by game version

Reuse the provider already preferred by the skill or explicitly requested by the user. Resolve its matching game section before trying another source. These entry points were inspected on **2026-10-04**; verify the actual page/report's game, expansion, phase/build and scope at use time. A site section existing does not establish complete API, talent or character-state coverage. Do not claim to have read blocked/JavaScript-only content.

Other already-established sources such as Icy Veins, Warcraft Wiki or dedicated class guides remain available for a concrete missing section or an explicit user preference. Do not broaden the provider roster merely because the player uses another version. Name the specific source gap and preserve source provenance when falling back.

Localized Wowhead paths put the edition before the locale, for example [MoP Classic German achievements](https://www.wowhead.com/mop-classic/de/achievements). Preserve both components and the entity ID; use a verified canonical edition link if the localized page cannot be checked. Do not map a Classic or Forever tooltip to Retail's `nether.wowhead.com` data simply by retaining the same numeric ID.

WCL documents Classic `talentPoints` as tree totals; those totals cannot reconstruct individual selections. Provider access, complete talent evidence and a compatible import format must be verified separately. [API documentation](https://www.warcraftlogs.com/api/docs), [CombatantInfoEvent fields](https://www.warcraftlogs.com/scripting-api-docs/warcraft/interfaces/RpgLogs.CombatantInfoEvent.html), [Classic routing guidance](https://www.archon.gg/classic-mop/articles/news/fresh-vanilla-on-warcraft-logs).

Website coverage is separate from local-helper support. The bundled WCL sampler/modern talent exporter, Raider.IO sample diagnostic and automatic source-refresh bundle currently implement Retail paths. Reuse another edition's published guides and supported exports directly; enable automated sampling/import only after a real response/fixture and compatible codec have been validated. Do not create a new integration during an ordinary gameplay request.
